# 师途 AI（ShituAI）

> 面向师范生的 AI Agent 应用：自动爬取教师招聘公告，按个人条件智能匹配岗位，生成备考计划并模拟结构化面试。

## 一、为什么做这个

我是湖南农业大学教育技术学专业大三学生，身边同学都在面临三个真实痛点：

1. **教招公告散**：湖南教师招聘网、各地市教育局公众号、高校人事网，公告分散，漏看一个可能就错过报名；
2. **条件匹配难**：学历、专业、户籍、资格证学段、是否师范生……一个个岗位对照条件筛，费时费力还容易看错；
3. **面试没头绪**：教招结构化面试、教资面试问法灵活，自己练没人点评。

本项目基于开源项目 [career-ops](https://github.com/career-ops-hq/career-ops) 二次开发，把它原本"互联网行业求职助手"的能力，迁移到师范生教招场景。

---

## 二、核心功能（Demo v0.1）

| 模块 | 功能 | 说明 |
|---|---|---|
| 📡 公告聚合 | 爬取湖南省内教师招聘公告 | 首期接入湖南教师招聘网、部分地市教育局站点 |
| 🎯 岗位匹配 | 按个人条件自动打分（1-5 分） | 输入学历、专业、教师资格证学段、户籍、期望地区，自动筛掉不符合条件的岗位 |
| 📝 备考计划 | 生成个性化备考时间表 | 根据距笔试/面试剩余天数，输出每日任务拆解 |
| 🎤 面试模拟 | 大模型扮演评委提问并点评 | 覆盖教育热点、教学设计、应急处理三类高频题型 |
| 📄 材料生成 | 生成结构化报名材料初稿 | 自荐信、个人陈述、简历要点 |

> 当前版本已跑通"输入我的条件 → 输出 5 个匹配岗位 → 生成一段面试模拟问答"完整链路。

## 三、技术栈

- **语言**：Python 3.10
- **LLM 接入**：豆包 / DeepSeek API（可切换）
- **爬虫**：requests + BeautifulSoup（首期静态页为主）
- **提示词工程**：针对教招场景重写 system prompt，注入教育政策与教学法常识
- **本地运行**：命令行交互，后续计划加 Streamlit 网页界面

## 四、快速开始

```bash
# 1. 克隆本仓库
git clone https://github.com/jiang-chenjie-me/shitu-ai.git
cd shitu-ai

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置大模型 API（在 .env 里填）
# LLM_API_KEY=your_key
# LLM_BASE_URL=https://ark.cn-beijing.volces.com/api/v3

# 4. 运行
python main.py
```

首次运行会引导你录入个人条件（学历、专业、资格证、期望地区），之后自动拉取最新公告并输出匹配结果。

## 五、相对原项目改了什么

| 原 career-ops | 师途 AI 改造后 |
|---|---|
| 扫描 Boss直聘 / 拉勾等互联网 JD | 改为爬教师招聘公告与教资动态 |
| 按互联网岗位描述简历 | 改为按师范生条件（专业对口、资格证学段、户籍限制）匹配 |
| 模拟技术面试（算法、项目深挖） | 改为模拟教招结构化面试 + 教资面试 |
| 输出 ATS 互联网简历 | 输出教师招聘自荐信 + 报名材料要点 |
| 提示词面向技术岗 HR | 提示词注入教育政策、教育学/心理学考点 |
